# Luna implementation transcripts

This directory stores the audit trail from local Luna or other implementation agents.

Each completed implementation cycle must add a dated Markdown transcript here.

Naming convention:

`<YYYY-MM-DD>-<project-or-page>-completion.md`

Example:

`2026-09-14-studysprout-completion.md`

A completion transcript should contain enough information for a later reviewer to understand what Luna was asked to do, what it actually changed, what validation it ran, what failed, how failures were corrected, which screenshots were reviewed, and what remains unresolved.

Required fields:

- task/prompt received;
- material decisions;
- changed files;
- commands run;
- validation results;
- screenshot review;
- production verification;
- failures and fixes;
- unresolved items/placeholders;
- intentional design deviations;
- final commit SHA;
- protected-file integrity confirmation.

Do not treat deployment success alone as completion evidence.
