# Visual reference

Preferred composition: warm editorial cream background, restrained forest/sage palette, large serif headline, real child writing on paper, small robot beside the child as tutor rather than protagonist, minimal sections, and generous whitespace. Desktop/tablet/mobile must feel like one design.

The bundled hero asset is `public/assets/hero-child-robot.svg`. Use it in the first implementation. The child + robot image must remain visible on mobile.

Concept renders contain generated text/device-frame artifacts. Do not copy those artifacts; use exact copy from `spec/site-contract.json` and build real responsive HTML/CSS.

Visual acceptance priorities: (1) hero image on mobile, (2) thesis understood immediately, (3) market gap obvious before feature detail, (4) three compact principles, (5) calm sparse page, (6) robot is not framed as a friend or emotional companion.
